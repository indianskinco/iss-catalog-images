# Indian Skin Store — catalogue image mirror

Public, crawlable mirror of primary product photos for the Google Merchant
Center and Meta (Instagram/Facebook) product feeds. The live store's images
are hotlink-protected and return 403 to shopping crawlers; this mirror exists
only so Google and Meta can fetch the main product image.

- `p/<item_id>.jpg` — clean primary pack photo, one per product.
- Not affiliated with image display on the website itself.
